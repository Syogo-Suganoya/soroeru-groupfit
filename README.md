# ソロエル

グループ全員のバーチャル試着を1枚の「集合プレビュー」に合成し、衣装かぶり・浮きを事前に検知する
グループ集合試着エージェントです。

結婚式のお呼ばれ・成人式・コスプレの合わせなど、「並んだときの見え方」を当日ではなく事前に確認できます。

## 使い方 — 友人4人でお呼ばれ

4人で結婚式に出る場面です。画像はすべて実際の画面です。

### 1. 幹事がルームを作る

イベント名・開催日・ドレスコードを入れます。

<img src="web/shots/01-create.png" width="300" alt="ルームを作る画面。イベント名、開催日、幹事の名前、ドレスコードを入力し、ルームを作成ボタンを押す">

### 2. 招待URLから参加する

届いたURLを開いて、自分の名前を選びます。

<img src="web/shots/02-enter.png" width="320" alt="あなたはどなたですか、と尋ねる画面。さおり・みずき・あかね・ゆいの4人が並び、それぞれ衣装ずみか衣装まだかが出ている">

### 3. 試着して決め、同意する

候補を試着して衣装を決めます。

<img src="web/shots/03-fitting.png" width="720" alt="ゆいさんのダッシュボード。上に衣装の確定・同意・かぶり・開催までの数字が並ぶ。左上の「衣装を選ぶ」にドレスの候補が3着、右に「あなたのすること」、下に集合プレビュー">

### 4. 総評

衣装が決まると、左上は集合プレビューに切り替わります。

数字の帯のすぐ下には、全員が読む「グループの総評」が出ます。検知の結果をもとに AI が書いた、 全体の印象と、いちばん先に直すとよい点です。

<img src="web/shots/04-harmony.png" width="720" alt="みずきさんのダッシュボード。左上が集合プレビューになり、右に「あなたに関係する指摘」（さおりさんと色が近すぎる、色差 ΔE 1.95）とお知らせが出ている。右端のゆいさんは未同意のためシルエット">

### 5. 幹事は全体を見渡す

誰が未確定・未同意かが右上で一目でわかり、未確定の人へのリマインドもここから送れます。

<img src="web/shots/05-organizer.png" width="720" alt="幹事のさおりさんのダッシュボード。左に集合プレビューとグループ全体の指摘、右上にみんなの進み具合があり、ゆいさんだけ未確定・未同意">

## 今後の展望

- LINE 通知の live 実装（ポートの口だけ用意しています）
- 実写のバーチャル試着（現状は衣装の色・柄からイラストを描いています）
- 生成モデルによる高品質な集合プレビューの合成（現状は Pillow で描画しています）
- アプリ外への通知（Web Push・LINE）。通知はアプリを開いた人にしか届きません
- 成人式・コスプレのシーンプリセット（`app/domain/dresscode.py` に枠だけあります）
- 実EC連携（カタログのレンタルリンクはダミーです）
