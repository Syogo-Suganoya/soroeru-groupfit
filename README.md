# ソロエル

グループ全員のバーチャル試着を1枚の「集合プレビュー」に合成し、衣装かぶり・浮きを事前に検知する
グループ集合試着エージェントです。

結婚式のお呼ばれ・成人式・コスプレの合わせなど、「並んだときの見え方」を当日ではなく事前に確認できます。

## 使い方 — 友人4人でお呼ばれ

4人で結婚式に出る場面です。画像はすべて実際の画面です。

### 1. 幹事がルームを作る

イベント名・開催日・ドレスコードを入れます。会場のライティングもここで選べます。

<img src="web/shots/01-create.png" width="300" alt="ルームを作る画面。イベント名、開催日、幹事の名前、ドレスコード、会場のライティングを入力し、ルームを作成ボタンを押す">

### 2. 招待URLから参加する

届いたURLを開いて、自分の名前を選ぶだけです。インストールは要りません。

<img src="web/shots/02-enter.png" width="320" alt="あなたはどなたですか、と尋ねる画面。さおり・みずき・あかね・ゆいの4人が並び、それぞれ衣装ずみか衣装まだかが出ている">

### 3. 同意して、試着して決める

集合プレビューに顔を出すかは本人が決め、いつでも撤回できます。候補を試着して1着に決めます。

似合い度は並び順の目安で、「似合う / 似合わない」を断定するものではありません。

<img src="web/shots/03-fitting.png" width="560" alt="みずきさんの画面。1 集合プレビューに参加する（同意ずみ）、2 試着して衣装を決める、の2ステップがあり、ドレスの候補が3着並んで似合い度が出ている">

### 4. かぶりはその場で知らせる

誰かが決めるたびにプレビューが作り直され、かぶった本人にだけ色差の数値つきで届きます。

同意していないゆいさんは、シルエットのまま並びます。

<img src="web/shots/04-harmony.png" width="480" alt="集合プレビューに4人が並び、右端のゆいさんはグレーのシルエット。その下に、さおりさんとみずきさんの色が近すぎるという指摘と、色差などの数値、お知らせが出ている">

### 5. 幹事は全体を見渡す

誰が未確定・未同意かが一目でわかります。未確定の人へのリマインドもここから送れます。

<img src="web/shots/05-organizer.png" width="560" alt="幹事のさおりさんの画面。みんなの進み具合に4人の衣装と合成OK・確定のタグが並び、ゆいさんだけ未同意・未確定。下にグループ全体の指摘がある">

### 6. 全員そろったら仕上げる

会場の光に寄せて見え方を確かめ、記念ムービーを作れます。

<img src="web/shots/06-finish.png" width="560" alt="仕上げの画面。会場のライティングにホテル宴会場（夜）が選ばれ、記念ムービーを作るボタンと、夜の光で色味が落ち着いた4人の集合プレビューのムービーが出ている">

## 今後の展望

- LINE 通知の live 実装（ポートの口だけ用意しています）
- 実写のバーチャル試着（現状は衣装の色・柄からイラストを描いています）
- 生成モデルによる高品質な集合プレビューの合成（現状は Pillow で描画しています）
- 記念ムービーの音楽生成（GIF は無音です）
- アプリ外への通知（Web Push・LINE）。通知はアプリを開いた人にしか届きません
- 成人式・コスプレのシーンプリセット（`app/domain/dresscode.py` に枠だけあります）
- 実EC連携（カタログのレンタルリンクはダミーです）
